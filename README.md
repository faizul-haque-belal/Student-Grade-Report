Student Grade Report
  A beginner-level Python project for managing student grade reports.
  
Description:
This project allows users to enter student names and marks, calculate grades, and display a simple grade report. It is designed to practice Python fundamentals.

Features:
Enter multiple students
Validate marks (0–100)
Calculate grades
Display student report
Find the highest marks
Find the lowest marks
Calculate average marks
Count pass students
Count fail students

Language:python 3

Concepts Used:
Functions
Loops
Lists
Dictionaries
If-Else Statements
While Loop
User Input
